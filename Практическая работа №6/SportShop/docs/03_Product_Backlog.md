# Product Backlog — проект «СпортТовары»

## US-1. Товары с низким остатком

**Как** менеджер магазина, **я хочу** видеть список товаров с низким остатком, **чтобы** вовремя заказать новую партию.

**Критерии приёмки:**
- Отображаются товары, у которых суммарное количество ≤ 3.
- Список отсортирован по возрастанию количества.
- Если таких товаров нет — выводится сообщение «Нет товаров с низким остатком».

**Оценка:** 3 story points
**Приоритет:** Высокий



## US-2. Поиск товаров

**Как** менеджер, **я хочу** искать товары по названию и бренду, **чтобы** быстро находить нужные позиции.

**Критерии приёмки:**
- Поиск работает по подстроке без учёта регистра.
- Можно фильтровать по категории, цене от и до.
- Если ничего не найдено — выводится сообщение «Товары не найдены».

**Оценка:** 5 story points
**Приоритет:** Высокий



## US-3. Аналитика по категориям

**Как** менеджер, **я хочу** видеть аналитику по категориям, **чтобы** понимать, какие товары популярны.

**Критерии приёмки:**
- Выводится количество товаров по каждой категории.
- Данные отсортированы по убыванию количества.
- Возможен вывод в виде таблицы.

**Оценка:** 5 story points
**Приоритет:** Средний



## US-4. Оформление заказа

**Как** менеджер, **я хочу** оформлять заказ и сохранять его в JSON, **чтобы** не потерять данные о продажах.

**Критерии приёмки:**
- Заказ сохраняется в файл `orders.json`.
- Формат — JSON с полями `date`, `client`, `items`.
- Если файл уже есть — новый заказ добавляется к существующим.

**Оценка:** 8 story points
**Приоритет:** Высокий



## US-5. Журнал действий

**Как** менеджер, **я хочу** видеть журнал действий, **чтобы** отслеживать, кто и что делал в системе.

**Критерии приёмки:**
- Каждое действие записывается в журнал.
- В журнале есть дата, действие, пользователь.
- Журнал можно просмотреть за последние N записей.

**Оценка:** 3 story points
**Приоритет:** Средний



## US-6. Добавление товара

**Как** менеджер, **я хочу** добавлять новые товары в каталог, **чтобы** поддерживать ассортимент актуальным.

**Критерии приёмки:**
- Запрашиваются название, цена, категория, размеры.
- Товар появляется в общем списке.
- id присваивается автоматически.

**Оценка:** 2 story points
**Приоритет:** Высокий



## US-7. Удаление товара

**Как** менеджер, **я хочу** удалять товары из каталога, **чтобы** убирать устаревшие позиции.

**Критерии приёмки:**
- Товар удаляется по id или названию.
- Если товар не найден — выводится сообщение.
- Перед удалением запрашивается подтверждение.

**Оценка:** 2 story points
**Приоритет:** Средний



## US-8. Экспорт каталога в CSV

**Как** менеджер, **я хочу** экспортировать каталог в CSV, **чтобы** открывать его в Excel.

**Критерии приёмки:**
- Файл `catalog.csv` создаётся в папке `data/`.
- Колонки: id, name, price, category, sizes, quantity.
- Кодировка UTF-8.

**Оценка:** 3 story points
**Приоритет:** Низкий



## US-9. Скидки на товары

**Как** менеджер, **я хочу** устанавливать скидки на товары, **чтобы** стимулировать продажи.

**Критерии приёмки:**
- Скидка задаётся в процентах.
- Цена со скидкой отображается в каталоге.
- Есть возможность снять скидку.

**Оценка:** 5 story points
**Приоритет:** Низкий



## US-10. Уведомления о низком остатке

**Как** менеджер, **я хочу** получать уведомления о низком остатке, **чтобы** не пропустить момент для заказа.

**Критерии приёмки:**
- При запуске программы выводится список товаров с остатком ≤ 3.
- Список выделяется цветом (или пометкой).
- Можно отключить уведомления в настройках.

**Оценка:** 3 story points
**Приоритет:** Низкий
