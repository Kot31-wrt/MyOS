## О практике

В ходе учебной практики были последовательно выполнены десять практических занятий, охватывающих полный цикл разработки программного продукта: от анализа предметной области и проектирования архитектуры до тестирования, интеграции модулей, документирования и работы с системой контроля версий.

Основной инструментарий: язык Python, СУБД SQLite, среда VS Code, система контроля версий Git, разметка Markdown, редактор диаграмм Draw.io.



## Что было сделано

### 1. Границы операционной системы и нефункциональные требования

Определены границы учебной ОС: что реализуется полностью, а что имитируется. Описаны роли — обычный пользователь, администратор, система. Разработаны сценарии использования через системные вызовы. Сформулированы нефункциональные требования с метриками: производительность, надёжность, безопасность, поддерживаемость, ресурсоёмкость. Проведён анализ рисков. Создан базовый прототип: модули `db.py`, `syscalls.py`, `shell.py`.

### 2. Архитектура и API ядра

Построена диаграмма компонентов: `shell` → `syscalls` → подсистемы → `db`. Описаны контракты функций (предусловие, постусловие, побочный эффект). Спроектированы структуры данных: пользователь, файл, процесс, запись журнала. Реализованы заглушки системных вызовов с логированием в SQLite. Оболочка расширена командами `whoami`, `login`, `create`, `ls`, `ps`.

### 3. Анализ предметной области

Выбрана предметная область — страховая медицинская компания. Определена цель ИС, проведён анализ осуществимости. Описаны пользователи, требования к техническим средствам, системному ПО.

### 4. ООП и контроль версий

Изучены принципы объектно-ориентированного программирования: классы, объекты, свойства, методы. Выполнено ООП-проектирование для предметной области. Оформлены сущности, атрибуты, связи, концептуальная модель.

### 5. Основы Python в VS Code

Освоена работа в VS Code: создание проекта, запуск, горячие клавиши. Изучены базовые конструкции: переменные, типы данных, `print`, `input`, условия, циклы. Отработаны структуры данных: списки, словари, кортежи. Написаны функции: поиск, сортировка, фильтрация, работа с корзиной.

### 6. Scrum и Kanban

Изучены Agile, Scrum, Kanban. Составлен Product Backlog из десяти User Story с критериями приёмки. Спланирован спринт, создана Kanban-доска с WIP-лимитом. Проведены Daily Standup и ретроспектива.

### 7. Углублённая работа с Git

Освоен Git Flow: ветки `main`, `develop`, `feature/*`, `hotfix/*`. Созданы feature-ветки, выполнены слияния, разрешён конфликт слияния. Имитирован Pull Request. Выполнен hotfix с исправлением в `main` и `develop`. Построена история коммитов через `git log --graph`.

### 8. Отладка и тестирование (unittest)

Изучены виды тестирования: модульное, интеграционное, системное, регрессионное. Написаны модульные тесты с использованием `unittest`. Освоена отладка в VS Code: точки останова, Step Over, Step Into, Step Out. Написаны тесты для каталога, корзины, обработки ошибок.

### 9. Интеграция модулей

Монолитный файл разделён на модули: `catalog`, `cart`, `orders`, `analytics`, `storage`. Настроены импорты между модулями. Написаны интеграционные тесты полного цикла. Создан скрипт сборки `build.py`. Специально внесена и исправлена ошибка несовместимости форматов данных.

### 10. Документация и итоговый релиз

Написан `README.md` с описанием, установкой, запуском и структурой проекта. Создана техническая документация: API Reference, User Guide, Developer Guide. Оформлен итоговый отчёт о тестировании. Подготовлена презентация из семи слайдов. Сделан финальный коммит и создан тег версии **v1.0**.
