## Как сдавать новые работы

1. Создать папку с номером практики: `Практическая работа №N/`.
2. Положить в неё файлы: отчёт (`.pdf`, `.docx`) и, при необходимости, исходники.
3. Закоммитить и отправить:

       git add .
       git commit -m "Практическая работа N"
       git push
