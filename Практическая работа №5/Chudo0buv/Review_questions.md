# Ответы на вопросы

## 1. Как объявить переменную? Какие типы данных вы знаете?

Переменная объявляется присваиванием: `x = 5`, `name = "Иван"`.
Основные типы данных:
- `int` — целые числа (5, -3)
- `float` — дробные (3.14, 8990.0)
- `str` — строки ("текст")
- `bool` — логический (True, False)
- `list` — список ([1, 2, 3])
- `tuple` — кортеж ((1, 2))
- `dict` — словарь ({'ключ': 'значение'})
- `set` — множество ({1, 2, 3})
- `NoneType` — отсутствие значения (None)

## 2. Что делает print? Чем отличается от input?

- `print(...)` — выводит данные на экран.
- `input(...)` — читает данные, введённые пользователем, и возвращает строку.

Пример:
```python
name = input("Введите имя: ")   # ввод
print("Привет,", name)          # вывод
```

## 3. Для чего нужен цикл for? Чем он отличается от while?

- `for` — перебирает элементы последовательности (список, строку, range). Известно, сколько раз повторять.
- `while` — повторяет, пока условие истинно. Может быть бесконечным.

Примеры:
```python
for i in range(3):       
    print(i)

i = 0
while i < 3:           
    print(i)
    i += 1
```

## 4. Что делает range(5)? А range(1, 6)?

- `range(5)` — числа от 0 до 4: `0, 1, 2, 3, 4`.
- `range(1, 6)` — числа от 1 до 5: `1, 2, 3, 4, 5`.

Верхняя граница не включается.

## 5. Чем список отличается от словаря?

- **Список** (`list`) — упорядоченная коллекция, доступ по индексу: `lst[0]`.
- **Словарь** (`dict`) — неупорядоченная коллекция пар «ключ–значение», доступ по ключу: `d['name']`.

```python
lst = [10, 20, 30]
d = {'name': 'Air Max', 'price': 8990}
```

## 6. Что такое кортеж? Когда он удобен?

**Кортеж** (`tuple`) — неизменяемая последовательность: `(1, 2, 3)`.

Удобен, когда:
- данные не должны меняться (координаты, константы);
- нужен ключ словаря (списки нельзя, кортежи можно);
- возврат нескольких значений из функции: `return x, y`.

## 7. Как отсортировать список словарей по ключу?

Через `sorted()` и `lambda`:

```python
sorted_products = sorted(products, key=lambda p: p['price'])
```

По убыванию:

```python
sorted(products, key=lambda p: p['price'], reverse=True)
```

## 8. Что такое lambda?

**Lambda** — это короткая анонимная функция в одну строку.

```python
square = lambda x: x * x
print(square(5))   # 25
```

Часто используется в `sorted`, `filter`, `map` как «функция-ключ».

## 9. Как отфильтровать список с помощью спискового включения?

```python
cheap = [p for p in products if p['price'] < 6000]
```

С условием и преобразованием:

```python
names = [p['name'] for p in products if p['price'] > 5000]
```

## 10. Что делает return в функции?

`return`:
- возвращает значение из функции;
- завершает выполнение функции немедленно.

```python
def add(a, b):
    return a + b

result = add(2, 3)   # 5
```

Если `return` нет — функция возвращает `None`.
