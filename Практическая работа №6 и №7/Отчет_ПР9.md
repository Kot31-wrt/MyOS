## 2. Файлы модулей src/*.py

### src/catalog.py — работа с каталогом товаров

Содержит функции:

- `get_low_stock(products)` — возвращает товары с суммарным количеством ≤ 3, отсортированные по возрастанию остатка;
- `search_advanced(products, query, category=None, min_price=None, max_price=None)` — комбинированный поиск по названию, категории и диапазону цен;
- `count_by_category(products)` — словарь «категория → количество товаров», отсортированный по убыванию;
- `avg_price(products)` — средняя цена товаров в каталоге.

### src/cart.py — работа с корзиной

Содержит функции:

- `add_to_cart(cart, products, product_id, size, quantity)` — добавляет товар в корзину. Возвращает `(True, сообщение)` при успехе или `(False, сообщение)` при ошибке. Проверяет наличие товара, доступность размера и достаточное количество на складе;
- `remove_from_cart(cart, product_id, size)` — удаляет позицию из корзины по `id` и размеру;
- `update_quantity(cart, products, product_id, size, new_qty)` — изменяет количество товара в корзине с проверкой наличия на складе;
- `cart_total(cart)` — итоговая сумма корзины (`price × quantity` по всем позициям).

### src/orders.py — работа с заказами

Содержит функции:

- `create_order(cart, client_name, products)` — создаёт заказ из корзины. Возвращает словарь заказа с полями `date`, `client`, `items`, `total`. Если корзина пуста — возвращает `None`;
- `print_order(order)` — выводит заказ в консоль;
- `save_orders(orders, filename='orders.json')` — сохраняет заказы в JSON. Если файл существует — добавляет к существующим;
- `load_orders(filename='orders.json')` — загружает заказы из JSON.

### src/analytics.py — аналитика по заказам

Содержит функции:

- `total_revenue(orders)` — общая сумма всех заказов;
- `best_selling_product(orders)` — самый продаваемый товар по количеству;
- `average_order_total(orders)` — средняя сумма заказа.

### src/storage.py — работа с JSON

Содержит функции:

- `load_products(filename='data/products.json')` — загружает товары из JSON. Если файла нет — возвращает пустой список;
- `save_products(products, filename='data/products.json')` — сохраняет товары в JSON.

## 3. Файл tests/test_integration.py

Файл содержит 4 интеграционных теста в классе `TestIntegration`:

1. **test_full_cycle** — полный цикл работы приложения:
   - загрузка товаров из JSON через `load_products`;
   - добавление товара в корзину через `add_to_cart`;
   - создание заказа через `create_order`;
   - сохранение заказа через `save_orders`;
   - загрузка заказа через `load_orders`;
   - проверка, что сумма заказа совпадает.

2. **test_cart_total_matches_order_total** — сумма корзины (`cart_total`) совпадает с суммой заказа (`order['total']`).

3. **test_empty_cart_creates_no_order** — пустая корзина не создаёт заказ (`create_order` возвращает `None`).

4. **test_save_and_load_multiple_orders** — сохранение и загрузка нескольких заказов.

В `setUp` загружаются товары из `data/products.json`, создаётся пустая корзина, задаётся путь к тестовому файлу заказов `data/test_orders.json`.

В `tearDown` удаляется тестовый файл заказов после каждого теста.

## 4. Файл build.py

Скрипт локальной сборки выполняет четыре шага:

1. **`check_python_version()`** — проверяет, что версия Python не ниже 3.10. Если версия старая — сборка прерывается.

2. **`check_data()`** — проверяет наличие файла `data/products.json`. Если файла нет — сборка прерывается.

3. **`run_tests()`** — запускает все тесты из папки `tests` через `unittest discover`. Если хотя бы один тест упал — сборка прерывается.

4. **`run_app()`** — запускает `main.py`.

**Запуск:**

    python build.py

Скрипт останавливается на первой же ошибке: не та версия Python, нет файла данных или упали тесты — приложение не запускается.

## 5. Файл docs/15_Integration_Errors.md

В файле описана ошибка интеграции:

**Какая ошибка была внесена:** в `src/cart.py` в функции `add_to_cart` ключ `'name'` заменён на `'product'`.

**Как проявилась:** интеграционный тест `test_full_cycle` упал с ошибкой `AssertionError: 'name' not found in {'id': 1, 'product': 'Air Max', ...}`.

**Как была исправлена:** ключ возвращён обратно на `'name'`, тесты перезапущены — все прошли.

Это классическая ошибка интеграции: модуль `cart.py` и модуль `orders.py` используют разные имена для одного и того же поля. Модульное тестирование её не ловит — только интеграционное.
