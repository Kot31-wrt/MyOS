# Отладка в VS Code

## Что такое точка останова

Точка останова (breakpoint) — это метка, которую разработчик ставит на определённой строке кода. Когда программа доходит до этой строки, выполнение приостанавливается, и можно посмотреть значения переменных, выполнить строки по шагам, найти ошибку.

В VS Code точка останова ставится щелчком мыши слева от номера строки. Появляется красная точка.

## Где была точка останова

Точка останова была поставлена в функции get_low_stock на строке:

    return sorted(low, key=lambda p: p['total'])

Это последняя строка функции — перед возвратом результата. Именно здесь удобно проверить, что накопилось в переменной low и правильно ли отсортирован результат.

## Какие значения принимали переменные

После запуска отладки (F5) программа остановилась на строке return. В панели Variables были видны:

- products — список из 5 товаров (тестовые данные из блока if __name__ == "__main__":).
- low — список товаров с суммарным количеством ≤ 3. В него попали Air Max (1 + 2 = 3), Runfalcon (2) и другие.
- p — последний товар, который обрабатывался в цикле (Мяч Nike).
- total — сумма размеров последнего товара (10).

Также в панели Call Stack видно стек вызовов:

    get_low_stock   shop.py  13:1
    <module>        shop.py  81:1

Это значит, что функция get_low_stock была вызвана из модуля (блок if __name__ == "__main__":).

## Использование Step Over и Step Into

Step Over (F10) — выполняет строку, не заходя внутрь вызываемых функций. Удобно, когда нужно быстро пройти по коду, не углубляясь в детали.

Step Into (F11) — заходит внутрь функции, которую вызывает текущая строка. Использовалось на строке:

    total = sum(p['sizes'].values())

Нажатие F11 позволило зайти внутрь функции sum и увидеть, как она складывает значения словаря sizes.

Step Out (Shift+F11) — выходит из текущей функции обратно в вызывающий код.

## Какая ошибка была найдена

В ходе отладки ошибок в функции get_low_stock не обнаружено. Функция работает корректно:

- товары с суммарным количеством ≤ 3 попадают в результат;
- результат отсортирован по возрастанию total;
- если товаров с низким остатком нет — возвращается пустой список.

Отладка подтвердила, что логика функции соответствует ожиданиям, и тесты проходят успешно.

## Вывод

Отладка с точками останова — эффективный способ проверить работу функции пошагово. В VS Code это делается через:

- точку останова (щелчок слева от строки);
- запуск F5;
- панель Variables для просмотра значений;
- Step Over / Step Into / Step Out для перемещения по коду.
