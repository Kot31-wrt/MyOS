## Слайд 2. Цель и задачи

**Цель проекта:**  
Разработать консольное приложение для управления магазином спортивных товаров.

**Задачи:**

- вести каталог товаров с размерами и ценами;
- искать товары по названию, категории, цене;
- находить товары с низким остатком на складе;
- работать с корзиной (добавление, удаление, изменение количества);
- оформлять заказы и сохранять их в JSON;
- строить аналитику по продажам;
- покрыть код интеграционными тестами;
- оформить полную документацию.



## Слайд 3. Архитектура

Приложение разделено на модули в папке `src/`:

|     Модуль     |         Назначение         |
|                |                            |
|  `catalog.py`  | работа с каталогом товаров |
|   `cart.py`    |          корзина           |
|  `orders.py`   |          заказы            |
| `analytics.py` |         аналитика          |
|  `storage.py`  | сохранение / загрузка JSON |

**Точка входа:** `main.py`  
**Сборка:** `build.py`  
**Данные:** `data/products.json`

Схема:

    main.py
      ├── src/catalog.py
      ├── src/cart.py
      ├── src/orders.py
      ├── src/analytics.py
      └── src/storage.py  →  data/products.json



## Слайд 4. Основные функции

**Каталог (`src/catalog.py`):**

- `get_low_stock(products)` — товары с остатком ≤ 3;
- `search_advanced(products, query, category, min_price, max_price)` — комбинированный поиск;
- `count_by_category(products)` — аналитика по категориям;
- `avg_price(products)` — средняя цена.

**Корзина (`src/cart.py`):**

- `add_to_cart(...)` — добавить товар;
- `remove_from_cart(...)` — удалить;
- `update_quantity(...)` — изменить количество;
- `cart_total(cart)` — итоговая сумма.

**Заказы (`src/orders.py`):**

- `create_order(...)` — создать заказ;
- `print_order(...)` — вывести;
- `save_orders(...)`, `load_orders(...)` — сохранение / загрузка.

**Аналитика (`src/analytics.py`):**

- `total_revenue(orders)` — выручка;
- `best_selling_product(orders)` — хит продаж;
- `average_order_total(orders)` — средний чек.
