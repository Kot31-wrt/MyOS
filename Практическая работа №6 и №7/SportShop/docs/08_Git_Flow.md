# Git Flow для проекта SportShop

## Схема ветвления

main — стабильная версия продукта.
  ↑
  │ hotfix/* — срочные исправления
  │
develop — ветка интеграции новых функций.
  ↑
  │ feature/* — ветки для отдельных функций

## Ветки

- **main** — стабильный релиз. Сюда попадает только проверенный код.
- **develop** — основная ветка разработки. Все feature-ветки вливаются сюда.
- **feature/<название>** — ветка для отдельной функции.
- **hotfix/<название>** — ветка для срочного исправления ошибки в main.

## Правила работы

1. Новая функция — новая ветка `feature/*` от `develop`.
2. После реализации — слияние в `develop`.
3. Ветку `feature/*` после слияния удаляем.
4. Критическая ошибка в `main` — ветка `hotfix/*` от `main`.
5. Hotfix сливается и в `main`, и в `develop`, чтобы не потерять исправление.
