# PR: feature/search-advanced → develop

## Что сделано

Добавлена функция `search_advanced(products, query, category=None, min_price=None, max_price=None)` — комбинированный поиск товаров.

Функция поддерживает:

- поиск по подстроке в названии (без учёта регистра);
- фильтр по категории;
- фильтр по минимальной цене;
- фильтр по максимальной цене.

Все фильтры, кроме `query`, опциональны. Если параметр не задан — фильтр не применяется.

Функция добавлена в файл `shop.py`.

## Как проверить

1. Открыть терминал в корне проекта.
2. Запустить:

       python shop.py

3. В выводе должно появиться:

       Поиск 'max':
         Air Max

4. Дополнительно можно проверить с фильтрами:

       search_advanced(products, 'max', category='кроссовки', min_price=5000, max_price=10000)

   Ожидаемый результат: список кроссовок с «max» в названии и ценой от 5000 до 10000 руб.

5. Если ничего не найдено — функция возвращает пустой список `[]`.
